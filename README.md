# StockFlow — установка на GitHub Pages

## Файлы (все в корень репозитория или в папку `docs` / `gh-pages`)

| Файл | Назначение |
|------|------------|
| `index.html` | Приложение |
| `manifest.webmanifest` | PWA-манифест |
| `sw.js` | Service Worker (офлайн) |
| `icon-192.png` | Иконка 192 |
| `icon-512.png` | Иконка 512 |
| `apple-touch-icon.png` | iOS иконка (180×180) |
| `_nojekyll` | Отключает обработку Jekyll на GitHub Pages |

## Шаги на GitHub

1. Создайте репозиторий (или используйте существующий).
2. Загрузите **все** файлы из этой папки в корень репозитория.
3. **Settings → Pages**:
   - Source: **Deploy from a branch**
   - Branch: `main` (или `master`), folder: **/ (root)**
4. Откройте: `https://ВАШ_ЛОГИН.github.io/ИМЯ_РЕПО/`

## Установка на телефон

1. Откройте сайт в **Chrome** (Android) по **https**.
2. Меню → **Установить приложение** / **На главный экран**.
3. Разрешите **камеру**, если нужен сканер штрихкода.

Камера **не работает** при открытии через `file://` или `content://` — только HTTPS.

## Обновление

После загрузки нового `index.html` на GitHub обновите страницу или закройте PWA и откройте снова.
Кэш: `stockflow-v4` в `sw.js` — при смене версии увеличьте номер (например, `v5`), чтобы сбросить старый кэш у пользователей.
